# 电维智答｜竞赛增强网站

这是面向“AIC·AI+场景建造创新赛·赛道一：创新应用”的网页演示原型，项目定位为“建筑电气设备智能运维与故障辅助诊断平台”。

## 直接查看

双击 `index.html` 即可打开。也可以在当前目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## Streamlit Community Cloud

仓库根目录放入以下文件：

- `app.py`
- `index.html`
- `requirements.txt`

在 Streamlit Community Cloud 中选择 `app.py` 作为 Main file path 即可。当前版本不要求 Secrets，因为页面运行在浏览器演示模式。

## 当前版本边界

网页已经包含：

- 建筑配电房、施工临电、楼宇能耗和机电设备场景；
- 智能诊断表单与风险分级；
- 演示知识依据与安全处置边界；
- 本地浏览器问答记录；
- 运维工单文本导出；
- 知识库、评测看板和系统设置页面；
- 响应式布局，适合电脑和移动端浏览。

当前页面的诊断引擎是**浏览器演示规则引擎**，用于展示完整交互链路，不应在参赛材料中表述为已经接入 GPT、Qwen 或真实向量库。正式工程版应增加后端 API、授权规程解析、向量检索、模型调用、权限和审计日志，并以真实测试集重新统计指标。

## 参赛前必须补充

1. 使用经过授权的建筑电气规程、设备手册或脱敏案例替换演示引用；
2. 真实记录测试集、模型版本、样本量、引用准确率、拒答质量和响应时间；
3. 在技术报告和佐证材料中区分“原型演示值”和“真实测试值”；
4. 对高风险建议保留人工复核，不让系统直接控制现场设备；
5. 不要把 API 密钥写入 HTML 或公开 GitHub 仓库。
